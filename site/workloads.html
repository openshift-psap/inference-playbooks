Workloads

A workload describes benchmark traffic, not deployment geometry. GPU type and count, parallelism, and single-node or multi-node scope describe the serving configuration. The catalog shows only combinations backed by actual recipes.

8k/1k

GuideLLM generates synthetic text requests with a target of 8,000 prompt tokens and 1,000 output tokens. These are workload targets, not measured results.

The job exercises fixed concurrent streams with a controlled input/output shape. Use this profile when that synthetic request shape matches the question you want to investigate; it does not replay a multi-turn coding session.

The server must accept the requested input plus output tokens, including chat-template overhead. Selecting this workload does not configure the server's maximum model length.

Agentic workload

AIPerf AgentX replays long-context, multi-turn coding-session traces, using pre-canned assistant responses. Its traffic shape is not a fixed 8k/1k request.

Both context variants belong to the catalog's Agentic workload filter:

  • 128K cap: the harness sets --max-context-length 128000, filtering out larger traces. The server must accept the retained contexts; compare results only with runs using the same cap.
  • Uncapped / unlimited: the harness omits that cap. “Unlimited” means no harness context filter, not infinite model context. The server must accept every trace request in the corpus; server-side context rejections contribute to the context-overflow rate and can invalidate a run.

Neither variant sets the server's maximum model length. Use this profile to investigate trace-replayed session traffic, choosing the context variant to match the corpus coverage and server context support you intend to test.

Choose by traffic shape, compare like for like

8k/1k isolates a synthetic input/output shape; Agentic replays long-context session traffic. Neither label identifies the fastest recipe or guarantees performance on your application.

For meaningful comparisons, align the workload profile and context cap, trace corpus, tokenizer, hardware, model and serving image, and harness settings. Check run provenance and committed benchmark evidence before interpreting measurements. Unbacked measurements do not establish validation or promote recipe maturity.

The benchmark guide and linked job manifests are authoritative for current harness versions, images, replay settings, prerequisites, and artifact collection.
